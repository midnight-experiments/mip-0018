How to read a row:

- **Status** `covered`: the tests listed pass in CI (`docker/run.sh test`), unless marked *local chain* (end-to-end
  scripts that need `docker/local-stack`).
  `not testable here`: the reason is given.
- **Vectors** are the language-neutral fixtures in [`vectors/`][vectors] (ids as in its table). The reference
  consumer runs all of them in [`packages/codec/test/vectors.test.ts`][codec-vectors] and
  [`packages/consumer/test/vectors.test.ts`][consumer-vectors] (78/78 normative, 49/49 informative).
- **Mutation** `x`: [`packages/consumer/test/mutations.test.ts`][mutations] turns off the rule switch `x` of the
  decoder or reducer and checks that at least one normative vector then fails, so the vectors really
  test that rule — for zero extension (`zeroExtend`), which the MIP's Testing list has no vector for, at least one
  informative `INF-ZEXT` vector.
- MIP-internal links inside the verbatim requirements point to the pinned MIP text.

## Run the tests

```sh
docker/run.sh ci                                   # once: npm ci in the pinned image
docker/run.sh test                                 # every unit/runtime test above (CI)
docker/run.sh mip0018 -- vectors run               # the vectors against the reference consumer (runner contract)
docker/run.sh exec 'npx vitest run packages/consumer/test/mutations.test.ts'   # the rule mutations alone
docker/run.sh check:conformance-matrix             # this table against the pinned MIP text
```
